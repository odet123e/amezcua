Vínculos o enlaces en HTML

¿Qué es un vínculo?

Un vínculo o enlace permite navegar de una página web a otra, abrir un sitio externo o dirigirse a una sección.

Etiqueta principal

La etiqueta <a> se utiliza para crear enlaces. El atributo href indica la dirección de destino.
